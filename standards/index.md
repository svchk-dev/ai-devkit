# Shared engineering standards

These are the toolkit's defaults, not universal framework requirements. Follow
the consumer's explicit local requirements and documented exceptions. Do not
change installed toolkit files to customize a project.

| Work | Read |
| --- | --- |
| Adding, correcting or relocating a rule | [Rule ownership](rule-ownership.md) |
| Any maintained code, tests or executable fixtures | [Coding standards](coding.md) in full |
| Consumer project architecture | [Architecture default](architecture.md) |
| Laravel persistence, input, caching or events | [Laravel boundaries](laravel.md) |
| Selecting or reviewing test coverage | [Testing](testing.md) |
| Filament administration | [Optional Filament profile](filament.md) |
| Agent task/review/completion | [Agent workflow](workflow.md) |

Read affected callers and the project's actual specifications before behavior
changes. Generated upstream guidance is complementary; local rules and these
selected defaults retain their declared authority. Tool success alone does not
prove responsibility boundaries, semantic names or correct logical grouping.
